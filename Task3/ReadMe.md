## Дорожная карта изменений технологического ландшафта компании "Будущее 2.0"

### Технический радар

Вероятно, в компании используются какие-то инструменты для разработки, развертывания или мониторинга приложений (git, GitLab иди Bitbucket, Docker, Kubernetes ...), но т.к. они не упомянуты в тексте задания и в решении я не указывал их на радаре.

[Технический радар](./TechRadar.drawio)

- **Отказ от SQL Server 2008** обусловлен тем, что Microsoft прекратила поддержку технологии в 2019. Использование устаревшей технологии не безопасно
- **Применение Greenplum и ClickHouse** обусловлено тем, что эти хранилища разнонаправлены и способны эффективно предоставлять доступ к данным разного типа, они также легко масштабируются и оптимизированы для быстрого доступа к информации для аналитики
- **Применение java script для разработки фронтенда (React.js) и бэкенда (Node.js) портала бизнес аналитики** обусловлено тем, что это де факто технологический стандарт для такого рода решений. Также с таким стеком одна команда может работать над серверной и клиентской частями системы.
- **Python, Golang, Java** продолжают использоваться в существующих системах
- **Apache Camel** не является ограничением системы, поэтому его использование пока возможно без изменений  
- **Apache NiFi** выбран в качестве ETL платформы из-за гибкости интеграций и возможности легко настраивать ETL пайплайны, пользуясь графическим интерфейсом
- **Apache Airflow** изучается, как альтернативная технология на случай, если потребуется больше свободы при трансформации данных
- **Power Builder и PowerBI** могут продолжать использоваться сотрудниками и бизнес аналитиками компании

### Дорожная карта

[Дорожная карта в формате диаграммы](./Roadmap.drawio)

- Q3 2025
  - **Подготовка Apache NiFi, интеграция с сервисами компании**. Выполняется силами команды ETL платформы. Требуется поднять Apache NiFi на серверах компании, настроить автоматический деплой и обновление системы, подготовить репозитории с конфигами, интегрировать систему с сервисами компании.
  - **Подготовка схем данных витрин данных**. Команда бизнес анализа должна подготовить требуемые им для работы схемы данных для хранилищ витрин данных.
  - **Подготовка хранилищ витрин данных**. Команды витрины данных должна за этот квартал подготовить хранилища для интеграции с ETL платформой. Требуется поднять и настроить БД, необходимую инфраструктуру и обеспечить мониторинг системы.
  - **Интеграция сервисов и DWH с Apache NiFi**. Команды сервисов компании помогают интегрировать ETL платформу с их системами. 
  - **Подготовка тестовых сценариев и тестовых наборов данных**. На этом этапе команда QA вступает в работу и готовится тестировать систему.
- Q4 2025
  - **Интеграция Apache NiFi с хранилищами витрин данных**. На этом этапе можно выполнить интеграцию ETL платформы с хранилищами витрин данных. Далее потребуется обеспечивать поддержку команды бизнес аналитиков, которая будет настраивать ETL пайплайны под свои нужды.
  - **Настройка ETL пайплайнов**. Один из ключевых этапов работы команды бизнес аналитиков на этапе подготовки системы, требуется настроить передачу данных из существующих систем в развернутые ранее витрины данных.
  - **Разработка бэкенда портала бизнес аналитики**. Команда витрин данных занимается разработкой серверной части портала бизнес аналитики.
  - **Подготовка к миграции данных из DWH и изменению потоков данных черех ESB**. Пока настраиваются пайплайны команды действующих сервисов компании должны подготовить существующие системы к изменению потоков данных.
- Q1 2026
  - **Миграция данных из DWH, запуск ETL пайплайнов**. Ключевой этап разработки системы - миграция данных из DWH в хранилища витрин данных. Команды бизнес аналитиков и ETL платформы совместно отвечают за успех операции.
  - **Разработка фронтенда портала бизнес аналитики**. В это время команда портала разрабатывает фронтенд приложение.
  - **Миграция данных из DWH, перевод потоков данных**. Существующие системы переключаются на ETL платформу для передачи данных.
  - **Тестирование ЕTL пайплайнов и бэкенда портала бизнес аналитики**. Команда QA проводит комплексное теcтирование системы, в том числе нагрузочное тестирование платформы на заранее подготовленных наборах данных.
- Q2 2026
  - **Пробная эксплуатация системы, настройка профилей, отладка**. На этапе пробной эксплуатации команды бизнес аналитики, ETL платформы и портала работают совместно, чтобы отладить работу системы и починить баги, которые выявляют тестировщики
  - **Тестирование портала для бизнес аналитики**. Команда QA совместно с бизнес аналитиками проверяет, что все пользовательские сценарии для портала выполняются корректно.
